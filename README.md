A robot's wedding vow, one sentence under 200 characters: a machine promises its beloved a warm side of the charging dock, no update installed without asking first, and its final watt spent holding hands through the night. Funny and heartfelt at once — a vow only a robot could make, and only a lover would mean.

## Run it

```sh
python3 main.py
```

Writes the vow to `/output/entry.txt`. Python standard library only; deterministic — every run produces the same bytes.
